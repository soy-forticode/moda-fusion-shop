# Moda Fusión - Tienda Online

## 🛍️ Descripción
Tienda de ropa y accesorios con diseño moderno, visualización 3D y experiencia de compra optimizada.

## 🚀 Características
- ✅ 100% OFFLINE
- ✅ Diseño responsive y moderno
- ✅ Visualización 3D de productos con Three.js
- ✅ Sistema de carrito con LocalStorage
- ✅ Filtros por categoría
- ✅ Selector de colores en vivo
- ✅ SEO optimizado
- ✅ Seguridad en headers

## 📁 Estructura

MODA-FUSION-SHOP/
├── index.html # Página principal
├── productos.html # Catálogo completo
├── carrito.html # Carrito de compras
├── checkout.html # Pago
├── 404.html # Página de error
├── assets/ # Recursos estáticos
├── css/ # Estilos
├── js/ # JavaScript
└── vendors/ # Librerías externas



## 🛠️ Tecnologías
- HTML5 / CSS3
- JavaScript ES6+
- Three.js (3D)
- Font Awesome (offline)

## 📦 Instalación
1. Clona el repositorio o descarga los archivos
2. Abre `index.html` en tu navegador
3. ¡Todo funciona offline!
